# ☕ dojo-javinha

Repositório dedicado à prática e evolução nos estudos de **Programação Orientada a Objetos (POO) em Java**. Desenvolvido para a disciplina de POO do **2º período de ADS (2026.2)**. 🚀

---

## 📂 Estrutura do Repositório

O projeto está organizado por pacotes para facilitar a navegação e o estudo:

```text
dojo-javinha/
├── PDF's/                       # Fichas de exercícios e listas originais em PDF
├── src/
│   ├── EstruturasCondicionais/ # Exercícios de tomada de decisão (if/else, switch)
│   ├── EstruturaRepeticoes/     # Práticas com laços de repetição (for, while, do-while)
│   ├── EstruturaString/         # Manipulação de textos, métodos e algoritmos genéticos
│   └── ListaDeClasses/          # Criação de classes, objetos, atributos e métodos
└── README.md

```

---

## 📚 Enunciados e Fichas

As listas de exercícios e fichas passadas em aula estão guardadas na pasta **`PDF's/`**. Se precisar consultar o enunciado original de qualquer questão, é só dar uma olhada por lá!
